# Конвертер валют 💱

Небольшой учебный проект на Python: переводит сумму из одной валюты в другую по актуальному курсу и сохраняет историю конвертаций в базе данных. Работает как программа в терминале и как веб-сервис (REST API на FastAPI) с автоматической документацией.

Я сделал его, чтобы на практике разобраться, как устроены HTTP-запросы, REST API, тестирование, работа с базой данных, Docker и git.

## Что умеет

- конвертировать сумму между валютами по текущему курсу;
- выводить список доступных валют;
- проверять ввод: например, не принимает отрицательную сумму;
- сохранять каждую конвертацию в PostgreSQL и показывать историю (`/history`);
- работать через терминал или через веб-API;
- автоматически показывать документацию API (Swagger UI);
- запускаться одной командой через Docker Compose;
- проверяться автотестами (pytest).

## Технологии

- **Python 3**
- **FastAPI** + **uvicorn**: веб-API и сервер
- **PostgreSQL** + **SQLAlchemy** (драйвер psycopg): хранение истории
- **Docker** и **Docker Compose**: запуск приложения и базы данных
- **requests**: получение курсов валют по HTTP
- **pytest**: unit-тесты
- **git / GitHub**: история изменений

Курсы берутся из бесплатного API [exchangerate-api.com](https://www.exchangerate-api.com/). Данные там обновляются примерно раз в сутки, поэтому курс может немного отличаться от биржевого.

## Как запустить

Скачай проект:

```bash
git clone https://github.com/nEkit-pixel-01/currency-converter.git
cd currency-converter
```

### Вариант 1: веб-сервис с базой данных (Docker Compose)

Нужен установленный Docker с Docker Compose.

```bash
docker compose up -d --build
```

Команда соберёт образ приложения, запустит PostgreSQL и применит схему из `sql/schema.sql`. После запуска открой в браузере:

- **http://localhost:8000/docs**: интерактивная документация Swagger UI, где можно прямо в браузере попробовать запросы;
- **http://localhost:8000/currencies**: список доступных валют;
- **http://localhost:8000/history**: последние конвертации.

Остановить:

```bash
docker compose down
```

Важно: данные базы хранятся внутри контейнера, поэтому после `docker compose down` история очищается.

### Вариант 2: в терминале (без базы данных)

```bash
pip install requests
python converter.py
```

Программа спросит валюты и сумму, а потом покажет результат. История в этом режиме не сохраняется.

## Эндпоинты

| Метод | Адрес | Параметры | Что делает |
| --- | --- | --- | --- |
| GET | `/convert` | `amount`, `from_currency`, `to_currency` | переводит сумму из одной валюты в другую и сохраняет запись в историю |
| GET | `/currencies` | нет | возвращает список валют |
| GET | `/history` | `limit` (по умолчанию 10) | возвращает последние конвертации, новые сверху |

Пример запроса:

```
http://localhost:8000/convert?amount=100&from_currency=USD&to_currency=KZT
```

## База данных

Таблица `conversions`:

| Поле | Тип | Описание |
| --- | --- | --- |
| id | SERIAL, первичный ключ | номер записи |
| from_currency | VARCHAR(10) | исходная валюта |
| to_currency | VARCHAR(10) | целевая валюта |
| amount | NUMERIC | введённая сумма |
| result | NUMERIC | результат конвертации |
| created_at | TIMESTAMP | время запроса (UTC) |

Схема лежит в `sql/schema.sql`, примеры запросов (последние конвертации, количество и сумма по валютам, самая частая пара) в `sql/queries.sql`.

## Тесты

```bash
pip install pytest requests
pytest -v
```

Сейчас написано 3 теста для функции `convert()`. Они проверяют, что конвертация считает правильно и что некорректные данные (например, отрицательная сумма) обрабатываются как надо. База данных для запуска тестов не нужна.
