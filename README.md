# Конвертер валют 💱

Небольшой учебный проект на Python: переводит сумму из одной валюты в другую по актуальному курсу. Работает двумя способами: как программа в терминале и как веб-сервис (REST API на FastAPI) с автоматической документацией.

Я сделал его, чтобы на практике разобраться, как устроены HTTP-запросы, REST API, тестирование и работа с git. Проект ещё развивается.

## Что умеет

- конвертировать сумму между валютами по текущему курсу;
- выводить список доступных валют;
- проверять ввод: например, не принимает отрицательную сумму;
- работать через терминал или через веб-API;
- автоматически показывать документацию API (Swagger UI);
- проверяться автотестами (pytest).

## Технологии

- **Python 3**
- **requests**: получение курсов валют по HTTP
- **FastAPI** + **uvicorn**: веб-API и сервер
- **pytest**: unit-тесты
- **git / GitHub**: история изменений
- **Docker** 

Курсы берутся из бесплатного API [exchangerate-api.com](https://www.exchangerate-api.com/). Данные там обновляются примерно раз в сутки, поэтому курс может немного отличаться от биржевого.

## Структура проекта

## Как запустить

1. Скачай проект:

```bash
git clone https://github.com/nEkit-pixel-01/currency-converter.git
cd currency-converter
```

2. Установи зависимости:

```bash
pip install fastapi uvicorn requests pytest
```

### Вариант 1: в терминале

```bash
python converter.py
```

Программа спросит валюты и сумму, а потом покажет результат.

### Вариант 2: как веб-сервис

```bash
uvicorn main:app --reload
```

После запуска открой в браузере:

- **http://127.0.0.1:8000/docs**: интерактивная документация Swagger UI, где можно прямо в браузере попробовать запросы;
- **http://127.0.0.1:8000/currencies**: список доступных валют.

### Вариант 3: через Docker

Собрать образ и запустить контейнер:

​```bash
docker build -t currency-converter .
docker run -d -p 8000:8000 currency-converter
​```

После запуска документация будет доступна по адресу http://localhost:8000/docs.
Остановить контейнер: `docker ps`, затем `docker stop <имя контейнера>`.

Эндпоинты:

| Метод | Адрес | Что делает |
| --- | --- | --- |
| GET | `/convert` | переводит сумму из одной валюты в другую |
| GET | `/currencies` | возвращает список валют |

Точные названия параметров запроса можно посмотреть в `/docs`.

## Тесты

```bash
pytest -v
```

Сейчас написано 3 теста для функции `convert()`. Они проверяют, что конвертация считает правильно и что некорректные данные (например, отрицательная сумма) обрабатываются как надо.
